# Gesture-Controlled 3D Particle Sphere

An interactive 3D particle sphere built with Python, OpenCV, MediaPipe, and NumPy.

The application uses real-time webcam hand tracking to control a particle sphere.

## Features

- 3,000-particle 3D sphere
- Real-time hand tracking
- Move one hand to control the sphere
- Pinch and hold to charge
- Release the pinch to explode the particles
- Use two hands to resize the sphere
- Finger count changes particle colors
- Toggleable webcam background

## Controls

| Input | Action |
|---|---|
| Move one hand | Move and rotate sphere |
| Pinch | Charge |
| Release pinch | Particle explosion |
| Two hands | Resize sphere |
| Finger count | Change color |
| B | Toggle webcam background |
| Q | Quit |
